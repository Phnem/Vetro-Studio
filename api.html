03Limits and infrastructure

30–600/min

requests per key, by plan: Basic 30, Pro 120, Ultra 600. A daily quota applies too.

50 · 40

up to 50 results per search and up to 40 books per batch request on Pro and Ultra (Basic: 20 and 10).

3 days

the app asks for the update manifest at most once in three days.

~19 s

to swap data tables between releases, with no downtime. v1 shipped on 12 Nov, v2 on 13 Nov.

10M

requests and 30M CPU-ms a month: the Workers Paid plan quota.

0

IP addresses or user agents logged. Only per-key request counters are kept. Read-only, with open CORS.
