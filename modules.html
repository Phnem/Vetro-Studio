What this is

Not libraries.
Recipes.

These depend on a particular UI stack, a navigation structure and a lot of taste, so a Maven artifact would be either useless or a leaky abstraction. Every module ships as an archive with exactly two files.

01

SKILL.md — for an AI agent

A detailed implementation prompt for people who build with an AI coding agent: exact numbers, hard rules, what to build and an acceptance checklist.

02

GUIDE.txt — for your hands

For people who write the code themselves: the methodology, pinned versions, the full reference code, usage, tuning and troubleshooting.

03

Real numbers only

Every number in both files comes from the shipping app. Nothing is “approximately like”.

01frostedglass.zip

Frosted
glass.

A matte, diffuse material — as opposed to “liquid” lens glass. It diffuses what is under it, so text on top stays readable over moving covers.

Eight layers, fixed order

  1. 01Live backdrop
  2. 02Local blur
  3. 03Saturation and contrast
  4. 04Neutral tint, after the blur
  5. 05Micro-grain
  6. 06One-pixel rim
  7. 07Inner highlight
  8. 08Wide soft shadow

Inside the archive: the material table for dark and light themes, the structural rules that stop the glass collapsing into a flat fill, and the full FrostedGlass.kt.

Depends on io.github.kyant0:backdrop:1.0.0 (check its licence) · Compose BOM 2025.12.00 · Kotlin 2.4.21. Blur needs Android 12+; below that a denser fallback material is used.

02animation.zip

Motion,
one table.

One table of (ζ, T) springs is the only source of truth: UI code never writes spring(…) by hand. The three patterns are compositions of those tokens.

  • A window out of a dock iconsharedBounds + scaleToBounds, separate enter and exit springs, content revealed after the shell has gained area.
  • A “…” popoverPops from the corner with a controlled overshoot and closes critically damped.
  • A notification stackArrive, fling and reflow with a cascade that needs no timers.

The caption on top of the video names the token running at that moment. Inside the archive: the token table with periods and stiffness, the conversion math and the code of all three patterns.

03download.zip

Chunked
download.

Several connections pull 1 MB chunks from one shared queue, so a slow connection owns a chunk, not a share of the file.

  • Resumes from the first missing chunk
  • Replaces slow connections mid-chunk
  • Re-resolves expired CDN links
  • Falls back to one stream without Range
  • Final name only after size and SHA-256 match

Needs OkHttp 5.4.0 (an HTTP/1.1 client — important) and kotlinx-coroutines 1.10.2. The portable version was run against the real release: interrupted at 12 MB, resumed from 12 MB, verified, no leftovers.

Benchmark

≈ 4.7× faster

The real v3.4.9-Stable APK from the GitHub CDN, 5 runs per method, methods interleaved, SHA-256 checked every run.

47.3 s

9.8 s
6 connections, chunk queue

The classic equal split is within noise of the chunk queue on this network: the speed-up comes from parallelism, while the queue’s value is resilience — resume, slow-connection replacement and no stitching pass. Your network will differ.
