# Маскот Vetro на сайте

Маскот — тёмный «обмылок» (мягкий скруглённый параллелепипед) с двумя оранжевыми светящимися глазами, руками-«шлангами»
и ногами. Это **тот же персонаж, что в приложении Vetro Collection** (пустые состояния, шторка поддержки). На сайт его
**переносят, а не рисуют заново**: любая «похожая» версия считается ошибкой. Весь риг и все анимации уже есть в виде
SVG/JS, и приложение (Kotlin) было перенесено с них один в один.

## Главные правила

1. **Не перерисовывать и не «улучшать».** Персонаж согласован пользователем в три итерации по видео. Форму корпуса,
   цвета, глаза, руки и тайминги не менять. Нужна новая поза/сцена — сначала в `mascot/mascot.html`, потом показать
   пользователю роликом или кадрами (`render.py`), потом переносить дальше.
2. **Источник правды — `mascot/mascot.html`.** `assets/js/mascot-core.js` из него генерируется
   (`python mascot/build_core.py`) и руками не правится.
3. **Все сцены — чистые функции времени.** `draw(t)` возвращает SVG-строку кадра для момента `t`. Никакой случайности,
   никакого состояния между кадрами, кроме одной поправки на запаздывание рук (её считает сам `sceneSvg`).
4. **Цвета — только из `THEMES` ядра** (`light`/`dark`) и `ORANGE = "#E85002"` (оранжевый бренда приложения). Тема
   выбирается по теме страницы, а не подкрашивается.

## Сцены

| id в ядре | Длина цикла | Как зовётся в приложении (`MascotScene`) | Когда показывать | Кадр для «без анимации», с |
|---|---|---|---|---|
| `question` | 6 с | `Question` | ошибка, источник не ответил (чешет затылок, над головой «?») | 2.0 |
| `think` | 6 с | `Think` | ждём данные / нет новых серий (рука у подбородка, облачко с точками) | 2.5 |
| `shrug` | 6 с | `Shrug` | пусто, ничего не выходит (пожимает плечами) | 2.0 |
| `search` | 8 с | `Search` | поиск без результатов (водит лупой) | 1.0 |
| `sad` | 8 с | `Empty` | пустая папка / полка (подписано «Пусто…») | 4.6 |
| `hello` | 6 с | `Hello` | приветствие, первый запуск | 1.5 |
| `coffee` | 9 с | `Coffee` (AnimD) | «поддержать проект» (кресло, нога на ногу, звезда, чашка) | 0.25 |

Каждый цикл замкнут: после `L` секунд кадр равен первому, шва нет. Поля `label`, `hint`, `title`, `sub`, `btn` у сцены —
тексты **приложения** на русском, для подписи на сайте их брать нельзя (сайт двуязычный, тексты — через
`data-i18n`, см. `README.md`).

Для сайта естественно подходят: `hello` (герой/приветствие), `coffee` (блок «поддержать», Ko-fi), `search` (поиск по
каталогу книг без результатов, см. `docs/books-api.md`), `question` (ошибка загрузки), `think` (идёт загрузка).

## API ядра

`assets/js/mascot-core.js` выставляет `window.VetroMascot`:

| Член | Что делает |
|---|---|
| `VetroMascot.SCENES` | словарь сцен по id (поля `L`, `blob`, `label`, `hint`, `draw(t, uid)`) |
| `VetroMascot.ORDER` | `["question","think","shrug","search","sad","hello"]` (без `coffee`) |
| `VetroMascot.setTheme("light" \| "dark")` | выбирает палитру. **Глобально для следующих вызовов `sceneSvg`** |
| `VetroMascot.sceneSvg(id, t, size, enter = 1, uid = id)` | возвращает строку `<svg>` одного кадра |

Параметры `sceneSvg`:

- `t` — время в секундах от начала цикла; внутри берётся по модулю `L`, так что можно давать «сырое» время.
- `size` — сторона квадрата в CSS-пикселях (SVG с `viewBox 0 0 300 300`).
- `enter` ∈ [0..1] — появление: масштаб на пружине + проявление. `1` = уже появился. Приложение даёт 0→1 за 0.5 с,
  затем сцена крутится циклом.
- `uid` — **уникальный на экземпляр** суффикс id внутри SVG (градиенты, маски, клипы). Два маскота на странице с
  одинаковым `uid` ломают друг другу заливки.

## Встраивание (проверено в Chromium: два экземпляра, обе темы, без ошибок)

```html
<script src="assets/js/mascot-core.js"></script>
<div id="hero-mascot"></div>
<script>
function mountMascot(el, scene, { size = 360, theme } = {}) {
  const uid = scene + "-" + Math.random().toString(36).slice(2, 7);
  const dark = () => matchMedia("(prefers-color-scheme: dark)").matches;      // подставьте тему сайта, если она есть
  const still = { question: 2, think: 2.5, shrug: 2, search: 1, sad: 4.6, hello: 1.5, coffee: 0.25 }[scene];
  const draw = (t, enter) => {
    VetroMascot.setTheme(theme || (dark() ? "dark" : "light"));
    el.innerHTML = VetroMascot.sceneSvg(scene, t, size, enter, uid);
  };
  el.setAttribute("aria-hidden", "true");                  // декоративный; смысл несёт соседний текст

  if (matchMedia("(prefers-reduced-motion: reduce)").matches) { draw(still, 1); return; }   // как в приложении

  const t0 = performance.now();
  let raf = 0;
  const frame = (now) => {
    const s = (now - t0) / 1000;
    draw(Math.max(0, s - 0.5), Math.min(1, s / 0.5));       // 0.5 с на появление, дальше цикл
    raf = requestAnimationFrame(frame);
  };
  new IntersectionObserver(([e]) => {                       // за экраном не рисуем
    cancelAnimationFrame(raf);
    if (e.isIntersecting) raf = requestAnimationFrame(frame);
  }).observe(el);
}
mountMascot(document.getElementById("hero-mascot"), "hello");
</script>
```

Замечания по встраиванию:

- **Фон.** Маскот рассчитан на светлый фон (почти белый, у верха персиковый) и на чёрный (у верха тёмно-бордовый); пятно
  за ним (`blob`) подстраивается под тему. Фон блока должен быть близок к одному из двух, иначе силуэт теряется
  (в тёмной теме корпус почти чёрный, его держат тёплое пятно и контур). Точные градиенты — `THEMES.*.bg` в ядре.
- **Палитра сайта ≠ палитра маскота.** Сайт постерный (красный `#E1251B`, кремовый, чёрный), маскот — оранжевый
  `#E85002`. Менять цвет маскота нельзя (это нарушит «тот же персонаж»); если сочетание на странице режет глаз, это
  решение пользователя, а не агента: спросить.
- **Производительность.** Каждый кадр — пересборка SVG-строки (порядка десятков КБ) через `innerHTML`; это то же, что
  делает прототип для роликов. Замеров на слабых устройствах нет. Практика: один-два живых маскота на экране, пауза
  за экраном (как выше), при необходимости 30 к/с (пропускать каждый второй `frame`).
- **Размер.** `size` — пиксели, но SVG масштабируется по `viewBox`: чтобы сделать его резиновым, добавьте в CSS правило
  `#hero-mascot svg { width: 100%; height: auto; }` (правило в таблице стилей переживает пересборку `innerHTML`, а
  стиль, поставленный из JS на сам `svg`, нет).
- **Не подключать** зерно-дизеринг (`#grain`) и `renderAt`: это только для видеороликов (иначе в 8-битном mp4 градиенты
  идут полосами).
- **Скорость сцен** задана временем кадра, не «скоростью»: чтобы замедлить, умножайте `t`, а не меняйте сцену.

## Правки пользователя по ригу (не откатывать)

- Руки — гибкие «шланги» с изгибом и запаздыванием, стык с корпусом скруглён галтелью, не «дубины на одной точке».
- Корпус поворачивается по трём осям (`yaw`, `pitch`, `rot`) плюс наклон от ступней (`lean`); силуэт однотонный, без
  видимых граней. Корпус — суперэллипсоид (n≈4.2), лицо на плоскости передней грани; объём — один непрерывный градиент
  в плоскости передней грани (стопки слоёв дают полосы).
- В тёмной теме корпус почти чёрный `#16181C` (серый `#2B3038` отклонён); в светлой — `#2B3038`.
- Масштабы в SVG пишутся с 5 знаками (с 2 знаками дыхание шло ступеньками).
- Smear-кадры допустимы, но умеренно. Рука/бедро перед корпусом не «приклеиваются» резко: корень растворяется маской.
- `coffee` (AnimD) одобрена пользователем; живёт в шторке поддержки приложения.

## Как менять или добавить сцену

1. Правка в `mascot/mascot.html` (в объекте `SCENES`, сцена = `L`, `blob`, `draw(t, uid)`).
2. Посмотреть: `python mascot/render.py stills grid dark 0.5 1.2 2.0` (кадры → `mascot/stills/`) или ролик
   `python mascot/render.py grid light`. Показать пользователю.
3. Пересобрать ядро: `python mascot/build_core.py`.
4. Если сцена нужна и в приложении — перенести в `MascotScenes.kt` (репозиторий приложения): Kotlin там это
   тот же `draw(t)`, порт один в один.

Зависимости `render.py`: `pip install playwright imageio-ffmpeg` и `playwright install chromium`. Запуск из любой
папки; читает `mascot/mascot.html` рядом с собой.
