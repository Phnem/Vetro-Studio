# API каталога книг Vetro (`api.vetrostudio.bid`)

Публичное read-only API: поиск по каталогу книг и аудиокниг (268 840 произведений), карточка книги, обложки.
Тот же каталог, что стоит в приложении Vetro Collection первым источником для аудиокниг. Регистрации и cookie нет,
о вызывающем ничего не сохраняется. **Доступ по ключам:** сейчас ключ необязателен, но скоро станет обязательным; ключ сайта и порядок работы с ним
описаны в `docs/api-key.md` (его надо слать во всех запросах).

**Источник правды по коду и данным — репозиторий приложения** (`D:\AndroidStudioProjects\Vetro-collection`):
`tools/books-api/` (Worker, `README.md`, тесты), `book-dictionary/v2/` (сборка данных), `docs/adr/0002-book-catalog-index-v2.md`.
Этот файл — то, что нужно знать, чтобы подключить API к сайту. Если ответ API разошёлся с описанием здесь,
верить нужно `tools/books-api/src/worker.js`.

## Адрес

| | |
|---|---|
| Основной | `https://api.vetrostudio.bid` |
| Запасной (работает всегда) | `https://vetro-books-api.1234idelchik.workers.dev` |

Домен `api.vetrostudio.bid` работает (проверено 2026-11-13: `/v1/health` отвечает `200`, `Access-Control-Allow-Origin: *`),
сайт открывается на `https://vetrostudio.bid/`. На сайте API использует страница `api.html` (`assets/js/api.js`):
поиск, карточка книги, обложки; при сбое основного адреса она один раз переключается на запасной. **Перед подключением
проверьте**:

```bash
curl -s https://api.vetrostudio.bid/v1/health      # {"ok":true}  — домен готов
```

Если ответа нет, используйте запасной адрес. В коде сайта держите базовый адрес **одной константой**
(`const BOOKS_API = "https://api.vetrostudio.bid"`), чтобы переключить одним изменением.

## Браузер и CORS

API отдаёт `Access-Control-Allow-Origin: *` на все ответы (включая ошибки) и отвечает `204` на preflight
(`OPTIONS`). Можно звать `fetch` прямо со страницы на `phnem.github.io` и `vetrostudio.bid`, без прокси.
Заголовки `ETag`, `Content-Range`, `Content-Length`, `Accept-Ranges` доступны из JS. Только `GET`, `HEAD`, `OPTIONS`;
остальное → `405`.

## Маршруты

| Маршрут | Что отдаёт | Кэш |
|---|---|---|
| `GET /v1/health` | `{"ok":true}` | нет |
| `GET /v1/search?q=<текст>&limit=<1..50>` | поиск по всему каталогу (по умолчанию `limit=20`) | 10 минут |
| `GET /v1/books/<id9>` | книга + карточка деталей | 24 часа |
| `GET /v1/books?ids=1,2,3` | до 40 книг без деталей; неизвестные id пропускаются | 24 часа |
| `GET /covers/small/<id9>.avif?v=<cv>` | маленькая обложка (для списков) | год, `immutable` |
| `GET /covers/large/<id9>.avif?v=<cv>` | большая обложка (для страницы книги) | год, `immutable` |
| `GET /v1/manifest`, `GET /v1/index/...` | индекс для телефона (zstd). **Сайту не нужен** | — |

`<id9>` — девятизначный номер с нулями слева, строкой: `000000771`.

### Поиск

`/v1/search?q=orwell&limit=2` →

```json
{"q":"orwell","items":[
  {"id":"000032099","ru":"Джордж Оруэлл","en":"George Orwell","ra":"Gordon Bowker","f":4,"cv":0},
  {"id":"000066195","ru":"Автобиографическая заметка","en":"Autobiographical note by George Orwell","ra":"Джордж Оруэлл","ea":"George Orwell","y":1940,"f":7,"cv":13845035}
]}
```

- `q` нормализуется на сервере (регистр, диакритика, `ё→е`, транслит): «chayka», «Чайка», «чайка» находят одно и то же.
  В ответе `q` — уже нормализованная форма.
- Меньше 2 символов → `{"q":"…","items":[]}` без обращения к базе.
- Слова запроса — префиксы и сочетаются через И. Если нашлось почти ничего, ищется мягче (через ИЛИ).
- Сортировка по релевантности (bm25: название и автор весомее остального). Опечатки сервер **не** исправляет
  (это умеет только телефонный индекс), так что подсказывайте пользователю пробовать другую запись.

### Поля книги (`items[]` и верх `/v1/books/<id9>`)

| Поле | Значение |
|---|---|
| `id` | `"000000771"` |
| `ru`, `en` | название по-русски / по-английски (поле опускается, если пусто) |
| `ra`, `ea` | автор по-русски / по-английски |
| `y` | год первого издания |
| `f` | битовые флаги: `1` — есть обложка, `2` — обложка с ограничением лицензии, `4` — «ядро» (книга есть и в индексе телефона) |
| `cv` | версия обложки; кладётся в `?v=` ссылки на обложку. `0` — обложки нет |
| `alt` | (только в `/v1/books/<id9>`) прочие названия одной строкой |
| `detail` | (только в `/v1/books/<id9>`) карточка деталей, см. ниже |

Пустые и отсутствующие поля в JSON не попадают: **всегда проверяйте наличие**. Выбор языка: показывать `ru`,
если язык сайта русский и поле есть, иначе `en`, иначе то, что есть.

### Карточка деталей (`detail`)

Все ключи необязательны, списки обрезаны по размеру. `/v1/books/000000771` (реальный ответ, сокращён):

```json
{"id":"000000771","ru":"Фунты лиха в Париже и Лондоне","en":"Down and Out in Paris and London",
 "ra":"Джордж Оруэлл","ea":"George Orwell","y":1933,"f":5,"cv":7013464,
 "detail":{
  "orig":{"t":"Down and Out in Paris and London","l":"en"},
  "type":"literary_work",
  "alts":[{"t":"Фунты лиха в Париже и Лондоне","l":"ru"}],
  "authors":[{"n":"Джордж Оруэлл","l":"ru","r":"author"},{"n":"George Orwell","l":"en","r":"author"}],
  "tr":[{"l":"ru","t":"Фунты лиха в Париже и Лондоне","y":1933}],
  "ed":[{"t":"Down and Out in Paris and London","l":"en","pub":"Blackstone Audio Inc.","y":2007,"isbn":"9780786159024"}],
  "ext":{"wikidata":"Q1355487","openlibrary":"OL1168030W","fantlab":"9639"},
  "cover":{"src":"openlibrary_archive","page":"https://openlibrary.org/works/OL1168030W","w":288,"h":475}}}
```

| Ключ | Что это |
|---|---|
| `orig` | оригинальное название `t` и язык `l` |
| `type` | тип произведения (опускается для обычного) |
| `alts` | другие названия `{t, l}` |
| `authors` | `{n: имя, l: язык, r: роль}` |
| `series` | список `[{ru, en, pos?}]` — серии и номер в них |
| `tr` | переводы `{l, t, by?, y?}` |
| `ed` | издания `{t, l?, pub?, y?, isbn?, fmt?}` |
| `ext` | внешние id (`wikidata`, `openlibrary`, `fantlab`, …) → можно строить ссылки на источник |
| `desc` | описание `{t}` (текст на языке источника; есть примерно у 6% работ) |
| `gen` | жанры, список слов-кодов (`"fantasy"`, `"scifi"`, `"adventure"`, …) |
| `rate` | оценка читателей `{v, n}`: среднее и число голосов (например `{"v":8.5,"n":8389}`) |
| `ol`, `dur` | язык оригинала и длительность (смысл `dur` в документации не подтверждён; сайт его не показывает) |
| `cover` | откуда обложка: `src`, `page` (страница источника), `lic` (лицензия), `w`/`h` — размер `large` в пикселях |

Ссылку на источник обложки (`cover.page`) стоит показывать как подпись, когда она есть. Разрешение на раздачу всех
обложек, включая помеченные `f & 2`, дал владелец проекта; флаг оставлен, чтобы их можно было скрыть позже:
если когда-нибудь понадобится не показывать такие, достаточно проверять `(f & 2) === 0`.

## Обложки

Ссылка строится из полей книги, обложка есть только если `f & 1`:

```js
const cover = (b, large = false) =>
  (b.f & 1) ? `${BOOKS_API}/covers/${large ? "large" : "small"}/${b.id}.avif?v=${b.cv}` : null;
```

- Формат **AVIF**: Chrome, Edge, Firefox, Safari 16+ показывают его в `<img>` без доп. кода. На старых браузерах
  оставьте заглушку (`onerror` → плейсхолдер), не пытайтесь конвертировать.
- `?v=` обязателен для кэша: URL с версией неизменен год. Новая версия обложки = новый `cv`.
- `<img>` без CORS работает всегда. CORS-заголовок на обложках нужен только для `canvas`/`fetch`.
- Для списков берите `small`, для страницы книги `large`; задавайте `width`/`height` или `aspect-ratio`, чтобы
  не прыгала вёрстка. Нет обложки (`cv: 0`, нет флага `1`) → красивая заглушка в стиле сайта.

## Лимиты и ошибки

- Поиск и карточки: **120 запросов в минуту на клиента** без ключа; с ключом лимиты по тарифу (у ключа сайта, Ultra: 20 в секунду, 600 в минуту, 200 000 в сутки,
  см. `docs/api-key.md`). Дальше `429 {"error":"rate_limited"}` (не кэшируется), пауза в `Retry-After`.
  `health`, манифест и обложки лимитом не считаются. Делайте debounce 250–300 мс и `AbortController`.
- Ключ в запросах к API: заголовок `Authorization: Bearer <ключ>`, у обложек в `<img>` ещё `&key=<ключ>`. Полная документация для людей: страница `api-docs.html`.
- Ошибки — JSON `{"error": "<код>"}`: `not_found` (404, в том числе неверный путь/неизвестный id),
  `method_not_allowed` (405), `rate_limited` (429), `internal` (500).
- Кэширование: браузер и край Cloudflare держат поиск 10 минут, карточку сутки. Не добавляйте в запрос лишних
  параметров (`_=timestamp`), иначе кэш не сработает.

## Рецепт: поиск на сайте

```js
const BOOKS_API = "https://api.vetrostudio.bid";   // запасной: https://vetro-books-api.1234idelchik.workers.dev

let inflight;
async function searchBooks(q, limit = 12) {
  inflight?.abort();
  if (q.trim().length < 2) return [];
  inflight = new AbortController();
  const r = await fetch(`${BOOKS_API}/v1/search?q=${encodeURIComponent(q)}&limit=${limit}`, {
    signal: inflight.signal, headers: { Authorization: `Bearer ${BOOKS_KEY}` }   // BOOKS_KEY: см. docs/api-key.md
  });
  if (r.status === 429) throw new Error("rate_limited");
  if (!r.ok) throw new Error("http_" + r.status);
  return (await r.json()).items;
}

async function bookCard(id9) {
  const r = await fetch(`${BOOKS_API}/v1/books/${id9}`, { headers: { Authorization: `Bearer ${BOOKS_KEY}` } });
  return r.ok ? r.json() : null;
}

const title = (b, lang) => (lang === "ru" ? b.ru || b.en : b.en || b.ru) || "";
const author = (b, lang) => (lang === "ru" ? b.ra || b.ea : b.ea || b.ra) || "";
```

Обработка: при `AbortError` просто выходить; при пустом ответе показывать «ничего не найдено» с подсказкой
(опечатки сервер не правит); при `429` показать «слишком часто» и подождать.

Сайт двуязычный (`assets/js/i18n.js`): тексты интерфейса добавляйте по правилам из `README.md`
(`data-i18n` + русский перевод в словаре); сами названия книг приходят уже на двух языках.

## Чего API не делает

- Не отдаёт аудио, тексты книг и ссылки на прослушивание: только каталог (название, автор, год, обложка, детали).
  Источники озвучки подбирает приложение отдельно.
- Не исправляет опечатки и не ищет по смыслу (это делает индекс на телефоне).
- Не принимает запись: ни поиска «по пользователю», ни избранного.
- Ничего не знает о пользователях сайта: не вставляйте в запросы персональные данные.

## Как обновляются данные (для справки)

Новую версию каталога собирают и выкладывают из репозитория приложения: `book-dictionary/v2/README.md` (сборка) и
`tools/books-api/README.md` (выкладка в Cloudflare: D1, R2, Worker). Сайту ничего менять не нужно: формат и адреса
стабильны, обложки версионируются через `cv`.
