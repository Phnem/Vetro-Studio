# Vetro Studio (сайт)

Статический сайт-хаб экосистемы Vetro на GitHub Pages (`https://phnem.github.io/Vetro-Studio/`, домен `vetrostudio.bid`).
Чистые HTML/CSS/JS, без сборки и зависимостей; две языковые версии (EN/RU). Устройство сайта — в `README.md`.

## Если задача про…

| Задача | Читать сначала |
|---|---|
| подключить **API каталога книг** (поиск, карточки, обложки) на сайт | `docs/books-api.md` |
| **ключ сайта** для API (бессрочный, Ultra), как его слать и что поменять на сайте (уже сделано в `api.js`) | `docs/api-key.md` |
| **документация API для людей** (ключи, тарифы, методы, условия) | `api-docs.html`; источник текста — `docs/api/` репозитория приложения |
| поставить на сайт **маскота** (тот же персонаж, что в приложении) | `docs/mascot.md` |
| менять тексты, страницы, дизайн | `README.md` (раздел Design/Structure; строки через `data-i18n` + `assets/js/i18n.js`) |

Обе инструкции написаны так, чтобы по ним можно было работать без расспросов: адреса, форматы ответов, рабочие
фрагменты кода и список того, чего делать нельзя.

## Что нужно знать сразу

- **API книг** — `https://api.vetrostudio.bid` (запасной адрес — `https://vetro-books-api.1234idelchik.workers.dev`).
  Read-only, с CORS: на сайте вызывается прямо из браузера. Сейчас ключи необязательны, но скоро станут обязательными: сайту выдан свой ключ, как им пользоваться — `docs/api-key.md`. Перед использованием:
  `curl -s https://api.vetrostudio.bid/v1/health`. Код и данные API живут в **репозитории приложения**
  (`D:\AndroidStudioProjects\Vetro-collection`, папка `tools/books-api`), здесь только потребитель.
- **Маскот** уже перенесён: готовое ядро `assets/js/mascot-core.js` (`window.VetroMascot`), источник правды —
  `mascot/mascot.html`. Персонажа **не перерисовывать и не стилизовать заново**; новые позы — сначала в прототипе.
- Палитра сайта постерная (красный/кремовый/чёрный), оранжевый маскота `#E85002` — из приложения. Если одно мешает
  другому, это решение пользователя: спросить, не подгонять молча.
- Сайт двуязычный: любой новый видимый текст получает английский вариант в HTML и русский в `assets/js/i18n.js`.
- `graft/` — служебный граф кода (в `.gitignore`); `.claude/` — локальная конфигурация превью, не коммитить.

## Запуск и проверка

```bash
python -m http.server 3000      # http://localhost:3000
```

Предпросмотр настроен в `.claude/launch.json`. Для страниц, ходящих в API, проверяйте в браузере вкладку Network:
ответ должен быть `200` с `access-control-allow-origin: *`.
