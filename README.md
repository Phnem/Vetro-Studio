# Vetro Studio — Landing Page

Премиальный кинематографичный лендинг для [Vetro](https://github.com/Phnem/Vetro) — современного Android-приложения для организации библиотеки аниме и фильмов.

Дизайн построен на 3D-анимациях скролла, эффектах матового стекла (glassmorphism) и минималистичном интерфейсе, чтобы идеально презентовать главные фишки Vetro: распознавание по скриншотам и умную сортировку.

## 🛠 Технологии

* **Фреймворк:** Next.js 15 (App Router, Static Export)
* **Язык:** TypeScript
* **Стилизация:** Tailwind CSS v4
* **Анимации:** GSAP + ScrollTrigger (на базе `CinematicHero` от 21st.dev)
* **Иконки:** lucide-react

## 🚀 Локальный запуск

Убедитесь, что у вас установлен Node.js.

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск сервера для разработки
npm run dev
```
После этого сайт будет доступен по адресу: [http://localhost:3000](http://localhost:3000).

| Путь | За что отвечает |

## 🌐 Деплой (GitHub Pages)

Проект настроен для статического экспорта в папку `out/`. 

**Локальная сборка:**
```bash
npm run build
```

**Автоматический деплой (рекомендуется):**
Проект разворачивается через **GitHub Actions**. В настройках репозитория (`Settings` -> `Pages`) нужно выбрать `GitHub Actions` как источник (Source) и применить конфиг `Next.js`. При каждом коммите в ветку `main` сайт будет собираться и публиковаться сам.

**Ручной деплой в корень:**
Если хостинг требует, чтобы статика лежала прямо в корне ветки `main`, используйте кастомную команду:
```bash
npm run export:site
```
Это запустит билд и автоматически раскидает содержимое `out/` в корень репозитория.
